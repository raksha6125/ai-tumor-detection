Pancreatic Tumor Detection Using Deep Learning

About the Project

Pancreatic Tumor Detection is a mini-project that uses deep learning and image processing to analyze CT scan images for pancreatic tumor segmentation. The application is developed using Python and Flask, with a U-Net model for image segmentation.

The web application allows users to upload CT scan images, view the predicted segmentation mask and overlay, and display a stage estimate based on the implemented prediction logic.

**Note:** This project is for academic and research purposes only. Its predictions are not intended for clinical diagnosis or treatment decisions.

## Features

- User registration and login
- CT scan image upload
- Image preprocessing and validation
- U-Net-based image segmentation
- Visualization of the predicted tumor mask and overlay
- Stage estimation based on the implemented logic
- Prediction history
- Admin dashboard

## Technologies Used

- **Programming Language:** Python
- **Web Framework:** Flask
- **Deep Learning:** TensorFlow / Keras
- **Image Processing:** OpenCV
- **Numerical Computing:** NumPy
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **Model:** U-Net

## How It Works

1. The user logs in or creates an account.
2. The user uploads a CT scan image.
3. The application preprocesses and validates the image.
4. The trained U-Net model generates a segmentation prediction.
5. The application displays the segmentation mask, overlay, and stage estimate.
6. Prediction history can be viewed through the application, if enabled.

## Limitations

- Prediction quality depends on the training dataset and model performance.
- The model should be evaluated on appropriate, independently annotated clinical data before any medical use.
- Stage estimates generated by the application are based on implemented project logic and are not equivalent to a clinically validated cancer staging system.
